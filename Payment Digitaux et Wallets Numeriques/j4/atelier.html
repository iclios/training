Exemple A · Apple Pay

Comment ajouter une carte

Sur iPhone : Wallet orchestre · le TSP crée le token · l’émetteur autorise · le secret durable va dans l’eSE.

Étape Sur le téléphone Côté réseau
1 Ouvrir l’app Wallet (icône préinstallée iPhone) → + en haut à droite → Carte de débit ou de crédit —
2 Continuer → scan caméra ou Saisir les détails de la carte → Suivant · accepter les conditions Wallet → demande d’enrolment au TSP
3 Choisir la vérif. (SMS, appel, app banque) · saisir le code Émetteur valide le porteur (IDV)
4 Carte apparaît dans Wallet · Face ID / Touch ID prêts TSP provisionne le token dans l’eSE (UDK-AC locale)

Repère : tant que l’étape 3 n’est pas validée, aucun token n’est utilisable au POS.

Exemple B · Google Pay / Google Wallet

Comment ajouter une carte (Android)

Sur Android, l’app s’appelle Google Wallet (pas un dossier « Wallet » générique). Google Pay = le paiement ; Google Wallet = l’app où on ajoute la carte. Si absente : Play Store → « Google Wallet ».

Étape Geste exact sur Android Côté réseau
0 Tiroir d’apps → rechercher Wallet ou Google Wallet · sinon installer depuis le Play Store · se connecter au compte Google —
1 Ouvrir Google Wallet → en bas Ajouter à Wallet —
2 Carte de paiement → Nouvelle carte de crédit ou de débit → scan caméra ou saisie manuelle → Enregistrer et continuer Demande d’enrolment au TSP
3 Lire / Accepter les CGU émetteur · choisir la vérif. (SMS, e-mail, app banque) · saisir le code Émetteur valide le porteur (IDV)
4 Carte visible dans Google Wallet · activer NFC · Réglages → Appareils connectés → Préférences de connexion → Paiements sans contact → choisir Google Wallet (défaut) Token prêt · UDK-AC au TSP · HCE + LUK (credentials courts)

Repère : sans app Google Wallet + NFC défaut, le tap POS échoue même si la carte est « dans Google ». Secret long au TSP · LUK rechargés online.

Étape 5 · Transaction

Tap sur Lane 5000

Une fois la carte enrolée : montant TEST sur le Lane 5000 → CDCVM sur le phone → tap (card emulation) → suivre approve / decline.

Geste Ce qui se passe
Montant Saisir un montant TEST sur le Lane 5000
CDCVM Face ID / Touch ID / empreinte / code sur le phone
Tap Phone près du lecteur · Type A · EMV CL · token (pas le PAN)
Résultat AuthZ · TSP détokenise · émetteur décide · ticket TEST
