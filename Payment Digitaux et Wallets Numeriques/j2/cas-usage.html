Cas d’usage

Définition

Trois terrains typiques

Proximité, transport, P2P — pour chaque usage, situer les axes (statique / dynamique · tag 01, push / pull · MPM / CPM, closed / open) et la contrainte SI dominante.

Un usage n’impose pas un seul profil : on combine les axes (ex. magasin open + dynamique + pull).

Proximité

Commerce de proximité

Sticker ou écran caisse — le plus fréquent en pull (Merchant-Presented).

Magasin · Pull (MPM)

Marchand affiche · payeur scanne

Axe Profil fréquent
Push / pull Pull / MPM (sticker ou caisse)
Statique / dynamique Statique · 11 (petit commerce) · dynamique · 12 (caisse)
Closed / open Open souhaitable (multi-app)
Contrainte SI Montant saisi vs TTL · sticker cloné · notif caisse

Transport

Gares · bus · bornes

Volume, latence, parfois offline dégradé — autre profil que le commerce.

Borne · Validateur

Throughput · TTL court · closed fréquent

Axe Profil fréquent
Push / pull Les deux selon opérateur (MPM ou CPM)
Statique / dynamique Dynamique · 12 dominant (ticket / validation)
Closed / open Closed fréquent (opérateur / un rail)
Contrainte SI Temps de réponse · offline dégradé · anti-rejeu

P2P

Paiements de personne à personne

QR perso (proxy) — souvent pull vers un identifiant wallet / banque.

Payeur · Bénéficiaire

Proxy · open ou closed selon app

Axe Profil fréquent
Push / pull Pull / MPM vers QR perso (parfois push / CPM agent)
Statique / dynamique Souvent statique · 11 (proxy) · montant saisi
Closed / open Closed si mono-app · open si schéma P2P national
Contrainte SI KYC / plafonds · usurpation de QR perso
