1 · Objectif

Faire fonctionner une mini passerelle de paiement omnicanale :

  • 3 canaux : QR EMV MPM, carte, wallet token
  • 1 journal unique
  • lien avec le cours (AuthZ, QR, tokenisation, omnicanal)
En pratique

Ce n’est pas inventer un PSP réel : c’est utiliser le kit, enchaîner les 3 canaux, répondre aux questions sur les logs, puis exporter le fichier de logs (notation).

Sans NFC : le wallet illustre le modèle tokenisé (DPAN + crypto), pas le tap physique.

2 · Prérequis

  • PC Windows avec navigateur et accès réseau
  • Node.js LTS installé — voir §3 Installer Node.js
  • Navigateur récent (Firefox, Chrome, Edge…)
  • Téléphone : Android (APK) et/ou iPhone (Appareil photo pour scanner / copier)
  • Même réseau local entre PC et téléphone (Wi‑Fi ou câblé)

3 · Installer Node.js

Node.js n’est pas un fichier .js — c’est un logiciel qui exécute du JavaScript hors navigateur.

Le fichier server.js = script du kit. Sans Node.js (logiciel), start.bat ne démarre pas.

Windows Installer (.msi)

  1. Aller sur https://nodejs.org
  2. Télécharger LTS → Windows Installer (.msi) (ex. node-v22.x.x-x64.msi)
  3. Double-cliquer le .msi → suivre l’assistant d’installation
  4. Laisser « Add to PATH » coché si l’option apparaît
  5. Si une case du type « Automatically install the necessary tools » apparaît : inutile pour ce projet — la décocher
  6. Terminer (Finish) — aucun terminal à ouvrir

4 · Mise en route

Démarrer le serveur

  1. Ouvrir le dossier projet/kit/
  2. Double-clic sur start.bat
  3. Si CRITICAL : mettre le PC en réseau, relancer
  4. Sinon : noter l’URL affichée

Ouvrir le kit sur le PC

  1. Ouvrir un navigateur
  2. Saisir l’URL indiquée par le serveur
  3. En haut de page : bannière « Serveur prêt » + QR config (pour l’APK)

Télécharger l’APK (Android)

  1. Sur le téléphone : ouvrir le lien de partage (Drive)
  2. Télécharger pdwn-mpm-scanner.apk

Installer l’application Android

  1. Ouvrir le fichier .apk
  2. Autoriser l’installation si demandé (source inconnue / installer via cette app)
  3. Lancer l’app

Après le projet : remettre ce paramètre à sa valeur initiale (désactiver l’installation depuis des sources inconnues).

Relier l’APK au serveur

  1. Sur le PC : en haut de la page, repérer le QR config
  2. Dans l’app (écran Configuration) → Scanner le QR config
  3. L’app enregistre le serveur puis ouvre l’écran paiement (2 onglets)

Revenir à la config APK (rescanner)

Si l’IP du PC a changé, ou pour retenter le QR config :

  1. Sur l’écran paiement, juste sous l’URL du serveur (au-dessus des onglets) : bouton Changer le serveur / rescanner config
  2. L’écran Configuration réapparaît
  3. Scanner le QR config affiché en haut du navigateur PC
  4. L’app reteste la connexion puis revient à l’écran paiement

Payer avec l’APK

  1. Onglets : QR MPM · Wallet token
  2. Un seul bouton Scanner : le type de QR ouvre le bon onglet
  3. Un seul bouton Payer (selon l’onglet actif)

iPhone (sans APK)

  1. Pas de config téléphone : l’URL du kit s’ouvre uniquement sur le PC
  2. Appareil photo seulement pour le parcours (QR MPM / wallet) — pas pour un QR config
  3. Copier le texte scanné → coller dans le navigateur du PC → Payer

5 · Parcours pratique

Suivre les étapes dans l’ordre. Chaque canal produit des traces dans le journal (notation).

A — Prise en main

  1. Lancer le kit et ouvrir l’URL
  2. Observer le « Journal unique »
  3. Repérer les 3 canaux

B — Canal QR EMV MPM · cours J2

  1. « Générer QR MPM » (payload masqué à l’écran)
  2. Android : Scanner → onglet QR MPM → Payer
  3. iPhone : Appareil photo → copier le texte → coller dans le kit sur le PC → Payer
  4. Retenir : marchand présente · téléphone scanne = MPM

C — Canal carte + quiz · cours J1

  1. « Autoriser (mock) » → lire le log (path + stages)
  2. Répondre au quiz → Enregistrer la réponse
  3. Tester aussi une carte qui decline · enregistrer une 2ᵉ réponse

D — Wallet token · cours J3–J4

  1. « Provisionner » → QR credentials (DPAN + crypto masqués)
  2. Android : Scanner → onglet Wallet → Payer
  3. iPhone : Appareil photo → copier PDWNWALLET|… → coller dans le kit sur le PC → Appliquer → Payer
  4. Pas de quiz : le paiement suffit (voir le journal)

DPAN = Device Primary Account Number · Cryptogramme = preuve dynamique (mock ARQC).

E — Synthèse + export · cours J5

  1. Vérifier 1 QR + 1 carte (+ réponses quiz) + 1 wallet
  2. Expliquer le journal unique
  3. Exporter les logs → envoyer le fichier au formateur

6 · Livrable

Un seul livrable pour la notation

Le fichier produit par le bouton « Exporter les logs » dans le kit.

Saisir votre nom / binôme → télécharger → envoyer au formateur.

Le fichier contient (entre autres) :

  • date / heure d’export (exportedAt + exportedAtLocal)
  • contentHash (empreinte SHA-256 du journal)
  • les transactions du journal (QR · carte · wallet)
  • vos réponses quiz carte (studentAnswer)
  • l’historique d’activité (events)
  • les tokens provisionnés

Exportez en fin de projet, avant un reset éventuel du journal.
