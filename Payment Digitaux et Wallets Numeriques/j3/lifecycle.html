3.2 · Lifecycle

Network tokenization & lifecycle

Définition monétique

Qu’est-ce que le lifecycle du token ?

Ensemble des états et transitions d’un token : enrolment / provisioning, activation, usage en transaction, suspend / resume, delete. Distinct du cycle de vie de la carte source : on peut gouverner un device ou un canal sans résilier le PAN.

Provisionner ne suffit pas — le token vit et se gouverne.

Rôle

Lifecycle token

Crypto

  • Token ≠ cryptogramme

Ancrage

Cas pratiques

Cas 1 — Device perdu

  • Suspendre le token
  • Carte source intacte

Cas 2 — Nouveau device

  • Nouveau provisioning
  • Même PAN, nouveau contexte

Cas 3 — Suspicion fraude

  • Geler un token / device
  • Éviter une coupure globale

Cas 4 — Carte réémise

  • Re-liaison / re-provision
  • Gouvernance plus riche qu’un PAN

Clarification

Ce que ce n’est pas

Lifecycle token ≠ cycle carte

On peut suspendre un device sans résilier la carte du porteur.

Token ≠ cryptogramme

L’un est l’identifiant substitutif ; l’autre est la preuve dynamique d’usage.

≠ Cours SE / HCE

Ici : cycle et intro crypto. Secure Element, HCE, TEE = Jour 4.
