Jour 3 · Tokenisation

3.1 · Tokenisation

Domaines d’usage

Modes / domaines

Où on tokenise

Un domaine d’usage est le périmètre autorisé d’un token : dans quel canal, sur quel device, parfois chez quel marchand il peut servir. Ex. : token Watch (NFC) ≠ token carte enregistrée chez un marchand (COF) — ce sont deux wallets, deux domaines. Le rail Auth → Clearing → Settlement reste le même ; ce qui change, c’est qui tokenise, où vit le token et ce qui circule à la place du PAN.

In-store

Tap au POS

Le payeur ne tape pas son PAN : le device présente un token lié à l’appareil.

Wallet → Tap → TPE → Auth

Ce que voit le commerçant · ce qui circule

Domaine = device + proximité. Ce token ne sert pas en card-on-file web. Suite technique : Lifecycle · Provisioning.

In-app

Checkout natif

L’achat se fait dans l’application du marchand — token wallet ou vault PSP, pas une WebView.

App → Wallet / PSP → Backend → Auth

Paiement dans l’app · pas une page web embarquée

Deux voies possibles au même endroit « 2 » : wallet constructeur ou token PSP. Ex. : Uber, Deliveroo, billetterie.

E-commerce

Card-on-file

Le marchand réutilise la carte (1-clic, abonnement) en stockant un token — pas le PAN.

Checkout → PSP → Token stocké → Paiements suivants

Carte enregistrée côté marchand · abos / 1-clic

Card-on-file = wallet côté marchand / PSP. Suite : Architecture SI · Sécurité & PCI.

Synthèse

Canal ≠ lieu de stockage

Le canal (magasin, app, web) dit comment on paie. Le token dit où il vit. Même Apple Pay sur le même iPhone : souvent un seul token pour le tap et l’app — la carte enregistrée chez un marchand, c’en est une autre.

Légende — sigles

  • Wallet — portefeuille électronique (téléphone, Watch, ou côté marchand)
  • TSP — Token Service Provider (émet / gouverne le token)
  • PSP — Payment Service Provider (passerelle paiement du marchand)
  • OEM — constructeur du téléphone / OS (Apple, Google…)
  • COF — card-on-file · carte enregistrée chez le marchand
  • VTS / MDES — TSP Visa / Mastercard
  • TPE / POS — terminal de paiement · NFC — contactless
