1.3 · Architecture générale

Composants SI

Définition monétique

Qu’est-ce qu’un composant SI ?

Brique applicative ou technique qui porte une fonction monétique dans le système d’information : acceptation, acquisition, émission, post-transaction (clearing / settlement) — chez un acteur ou un prestataire.

Ce bloc répond à une seule question : dans quels SI ? — pas les rôles (acteurs), pas l’ordre du message (chaîne).

Frontière critique

Gateway ≠ Acquiring (pas toujours)

Même logique que PSP ≠ acquéreur sur la chaîne : la gateway est souvent la brique technique ; l’acquiring est le SI du rôle face au scheme.

Anti-confusion

Ne pas dessiner gateway + acquiring séparés par défaut — ni les fusionner par défaut. Regarder le montage (comme en Chaîne).

1 · Acquiring « maison »

Banque acquéreuse — gateway évent. interne / peu visible

Exemple POS banque « maison » branché sur le SI acquiring de la banque — pas de marque gateway PSP au milieu. Typique ; le contrat exact peut varier.

2 · Gateway devant l’acquiring

Deux briques — technique puis SI rôle scheme

Exemple Gateway / checkout d’un PSP technique qui envoie vers le SI acquiring d’une banque partenaire. Deux briques visibles. Typique ; le contrat exact peut varier.

3 · Gateway + acquiring chez le même PSP

Une logique SI côté acceptation — double étiquette

Exemple Paybox (écosystème Verifone) — ou Adyen / Stripe selon contrat : gateway et acquiring portés dans la même offre SI côté acceptation. Typique ; le contrat exact peut varier.

En salle : « chez vous, gateway et acquiring sont-ils séparés ? » — même question que montage PSP 1 / 2 / 3.

Cas pratiques

Cas 1 — Banque émettrice

  • Chez elle : issuing (+ évent. AuthN / ACS)
  • Hors SI : POS marchand, acquiring tiers
  • Lister « ce qui est à nous »

Cas 2 — Banque / PSP acceptation

  • Montage SI 1, 2 ou 3 ?
  • Gateway séparée ou intégrée ?
  • Issuing ailleurs

Cas 3 — E-com Paybox

  • Où est la gateway ?
  • Où commence l’acquiring ?
  • Où l’issuing décide ?

Exemple Checkout Paybox = gateway (souvent) ; acquiring selon que Paybox porte le rôle ou s’appuie sur une banque.

Cas 4 — Timeout d’autorisation

  • Quel composant suspecter en premier ?
  • Gateway · acquiring · réseau · issuing
  • ≠ decline fonds — blocs Auth / Online-offline

Clarification

Ce que les composants SI ne sont pas

≠ Acteurs

L’acteur est l’organisation / le rôle ; le composant est la brique dans son SI (ou chez un prestataire).

≠ Chaîne de valeur

La chaîne ordonne le message ; un maillon peut s’appuyer sur plusieurs composants.

Gateway ≠ always acquiring

Comme PSP ≠ toujours acquéreur — trois montages SI possibles.

Clearing ≠ settlement

Compensation vs règlement — développés dans les blocs suivants.

≠ Plateforme J5

Ici : cartographie fonctionnelle carte. Omnicanal = Jour 5.
