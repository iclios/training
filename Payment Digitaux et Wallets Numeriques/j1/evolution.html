Évolution des paiements

1 · Définir

Quatre notions

On fixe le vocabulaire avant les dates. Pour chaque notion : définition + ce qui change pour le SI.

Cash

Échange de valeur physique (pièce / billet) entre deux parties, sans intermédiaire technique de paiement.

SI : pas de message monétique temps réel

Carte

Instrument émis qui s’appuie sur un réseau pour faire autoriser puis régler une opération.

SI : chaîne auth / clearing / settlement

France : Carte Bleue (1967) · puce Moreno (1974) · proto B0 (Bull) avant EMV

Mobile

Le téléphone devient canal d’initiation du paiement (app, SMS, mPOS…).

SI : device + app ; rail souvent encore carte (parfois mobile money / A2A)

Wallet

Application qui orchestre un ou plusieurs moyens de paiement (souvent tokenisés) sur un device.

SI : token + device binding + UX — détail J3 / J4

2 · Relier dans le temps

Fresque schématique

Une seule lecture : ce qui s’ajoute à chaque étape. Les dates sont des ancres, pas un catalogue.

Chaque étape n’efface pas la précédente : elle s’ajoute dessus.

Question salle

Où commence vraiment votre métier SI banque dans cette fresque ?

Réponse attendue : à la carte — quand apparaissent réseau, messages et chaîne auth / clearing / settlement.

Repères carte — fil français + international

France — Carte Bleue (1967), consortium bancaire (BNP, Société générale, Crédit lyonnais, CCF, CIC, Crédit du Nord…) · Roland Moreno (1974), invention de la carte à puce · protocole B0 (Bull CP), standard français d’authentification à la puce avant le passage à EMV.

International (contexte) — Diners Club / Frank McNamara (1950), BankAmericard (1958) → Visa : la carte multi-commerçants existe déjà aux USA ; la France structure ensuite un modèle national (CB) puis une avance forte sur la puce.

3 · Distinctions utiles

Vocabulaire court

Électronique vs digital

  • Électronique : dématérialisation (carte, virement…)
  • Digital : canaux numériques (app, QR, wallet…)

Temps

  • Temps réel : autorisation online
  • Différé : clearing / settlement

Ancrage

Cas

« Paiement mobile » = toujours un rail carte ?

  • Souvent oui (wallet NFC / app sur rails carte)
  • Parfois non (mobile money, A2A)
  • Faire dire : mobile = canal ; le rail peut différer
Notes formateur
  • Ordre strict : définir → fresque → question SI
  • Ne pas noyer sous les dates ; 1 ancre par âge suffit
  • Ancrer le fil FR : Carte Bleue (1967) puis Moreno / B0 / EMV — ne pas confondre B0 (protocole puce) avec la naissance de la carte elle-même
  • Diners Club / BankAmericard = contexte international, pas le cœur du récit FR

Check de fin de bloc

  • Les 4 notions définies sans les confondre
  • Fresque restituée avec « ce qui s’ajoute »
  • Métier SI situé à partir de la carte
