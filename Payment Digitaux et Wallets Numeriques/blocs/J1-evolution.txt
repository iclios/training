3. DISTINCTIONS SYLLABUS
================================================================================
Paiement électronique vs digital
Pastilles cliquables → définitions en panneau.
Électronique = dématérialisé (messages / systèmes) — ≠ smartphone.
Digital = initié via canal numérique ; digital ⊂ électronique.
Web & normes amalgament souvent — ici on tranche.
Exemple : carte POS = électronique ; Apple Pay / QR = digital.

Paiement en ligne · proximité · in-app
Pastilles cliquables → définitions en panneau.
Canal = où s’initie — pas le rail.
In-app = paiement terminé dans une app marchand (ex. Uber) — EPC.
≠ site / navigateur · ≠ terminal magasin · ≠ wallet (trousseau + acceptation externe).
Un wallet peut être un moyen dans l’in-app ; le canal reste l’app.

Paiement temps réel vs paiement différé
Pastilles cliquables → définitions en panneau.
Paiement temps réel : auth online, Instant Payment…
Paiement différé : clearing / settlement, batch
Pont : vue message / argent · T+0 / post-tx
