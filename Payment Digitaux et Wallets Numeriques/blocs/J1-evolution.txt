================================================================================
2. DÉFINITIONS
================================================================================
Cash
Échange de valeur physique entre deux parties.
SI : pas de message monétique temps réel.

Carte
Instrument émis s’appuyant sur un réseau pour autoriser puis régler.
SI : auth / clearing / settlement.

Fil français (à privilégier en salle)
- 1967 : Carte Bleue (consortium bancaire FR)
- 1974 : Roland Moreno — carte à puce
- B0 (Bull CP) : protocole FR d’auth. à la puce, avant EMV
Ne pas confondre : B0 = standard puce, pas « la première carte ».

Contexte international
- 1950 : Diners Club (Frank McNamara)
- 1958 : BankAmericard → Visa

Mobile
Le téléphone devient canal d’initiation.
SI : device + app ; rail souvent carte (parfois mobile money / A2A).

Wallet
Application qui orchestre un ou plusieurs moyens (souvent tokenisés).
SI : token + device binding — détail J3/J4.


================================================================================
3. FRESQUE
================================================================================
Cash  --(+ réseau + messages)-->  Carte
      --(+ device canal)------->  Mobile
      --(+ orchestration/token)-> Wallet

Ancres : cash (monnaies→billets) · carte 1967 Carte Bleue (+ B0/puce) · mobile ~1997/2007 · wallet ~2011–2014

Question salle
Où commence le métier SI banque ? → à la carte.
