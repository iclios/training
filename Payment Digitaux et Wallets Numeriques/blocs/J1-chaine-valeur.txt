BLOC — FORMATEUR
Cours : Paiements digitaux & Wallets numériques
Jour 1 · Architecture générale
Bloc : Chaîne de valeur
Durée indicative : 30–40 min
Précédent : Standards EMVCo · Suivant : Composants SI
Sources normes : à affiner (modèles scheme, ISO messages…)


================================================================================
1. MÉTA FORMATEUR
================================================================================
Objectif
Restituer l’ordre Client → terminal → acquéreur → réseau → émetteur (+ retour),
distinguer vue message / vue argent, montrer que le digital change la façade
d’initiation (pas l’ordre), placer PSP sans casser le modèle.

Idée clé
« Chaîne de valeur = dans quel ordre le message passe — pas qui (acteurs),
pas dans quels SI (composants). Digital = canal, pas autre chaîne. »

Posture
1) Définition + schéma aller / retour (clic maillon)
2) Pont digital : 4 façades → même suite
3) Deux lectures : message vs argent
4) Variantes PSP
5) Ancrage : ordre · façade digitale · montage PSP


================================================================================
2. DÉFINITION
================================================================================
Séquence ordonnée des maillons + chemin de retour de la réponse.
Canonique : Client → Terminal → Acquéreur → Réseau → Émetteur


================================================================================
3. DEUX LECTURES
================================================================================
Vue message — demande / décision / réponse (ce bloc)
Vue argent — clearing → settlement → crédit marchand (blocs suivants)
L’OK émetteur ≠ règlement ≠ crédit marchand vécu


================================================================================
4. MAILLONS + VARIANTES PSP / ACQUÉREUR
================================================================================
Chaque hop = action (capture, route, aiguillage, décision…)

Trois montages (obligatoire en salle) + 1 exemple sous chacun
1) Banque acquéreuse seule — ex. POS banque « maison »
2) PSP devant l’acquéreur — ex. gateway PSP → banque partenaire
3) PSP-acquéreur — ex. Paybox (souvent) ; Adyen / Stripe selon contrat

Façades maillon 02 : POS · checkout · in-app · wallet → puis montage 1, 2 ou 3.
