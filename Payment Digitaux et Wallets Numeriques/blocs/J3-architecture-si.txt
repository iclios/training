JOUR 3 — Architecture SI tokenisation

Objectif pédagogique
Décrire la chaîne SI minimale et le flux demande → stockage → présentation Auth.

Chaîne SI
- merchant / wallet : demande d'usage
- TSP : émission et gouvernance
- network tokenization : domaine réseau
- bank issuer system : référence carte et AuthZ

Flux
1. Demande de token (canal → TSP / contrôles issuer)
2. Stockage / gouvernance (vault, états)
3. Présentation du token (+ crypto) dans le flux d'autorisation

Clarification
- TSP ≠ issuer
- le token ne remplace pas l'émetteur ni la décision AuthZ

Cas
- wallet mobile : demande wallet, gouvernance TSP, AuthZ issuer
- merchant tokenisé : substitut côté marchand, gouvernance hors SI direct
