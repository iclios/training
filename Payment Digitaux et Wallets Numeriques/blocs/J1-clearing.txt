================================================================================
1. MÉTA FORMATEUR
================================================================================
Objectif
Définir le clearing, situer Auth → Clearing → Settlement, distinguer single /
dual message, expliquer « qui doit qui » et le rôle d’une chambre (ex. STET).

Idée clé
« Le clearing, c’est la compensation entre banques : qui doit qui — pas le
paiement du commerçant, pas encore le settlement. »

Posture
1) Définition + intention
2) Situer (bandeau)
3) Single vs dual message
4) Schéma acteurs + créance + chambre (STET)
5) Rôle + cas


================================================================================
2. DÉFINITION
================================================================================
Compensation des opérations (souvent déjà autorisées) entre acquéreur et
émetteur via scheme / chambre → positions à régler.


================================================================================
3. SINGLE vs DUAL MESSAGE (2 schémas + seq-steps)
================================================================================
Dual message
Message 1 = autorisation (demande/réponse) — pas encore de clearing
… délai (capture / batch) …
Message 2 = présentation / compensation

Single message
Un message = autorisation + demande de compensation
Décision engendre déjà l’effet clearing (selon règles)
Ex. : certains DAB / flux financial

Point clé : dual → auth OK sans capture peut ne jamais clear ; single →
l’auth fait déjà l’objet d’une demande en compensation.
