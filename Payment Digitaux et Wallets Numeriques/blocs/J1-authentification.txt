BLOC — FORMATEUR
Cours : Paiements digitaux & Wallets numériques
Jour 1 · Flux transactionnel carte
Bloc : Authentification
Durée indicative : 20–30 min
Précédent : Composants SI · Suivant : Autorisation
Sources normes : à affiner (EMV ODA SDA/DDA/CDA, CVM, 3-D Secure, SCA / DSP2…)


================================================================================
1. MÉTA FORMATEUR
================================================================================
Objectif pédagogique
Distinguer AuthN carte (SDA/DDA/CDA), CVM (vérif./ID porteur) et AuthN e-com
(3DS/ACS) ; localiser dans le cycle EMV ; illustrer les canaux.

Idée clé
« Carte : AuthN = SDA/DDA/CDA (données/carte).
CVM = vérification / identification porteur (PIN, signature, No CVM).
E-com : AuthN = 3DS / ACS. Autorisation = accord émetteur. »

Posture
1) Définition AuthN selon canal + callout CVM ≠ AuthN carte
2) Cycle EMV : étape 3 = ODA · étape 4 = CVM
3) Quatre canaux → autorisation
4) Ancrage POS / checkout / wallet


================================================================================
2. DÉFINITION
================================================================================
AuthN carte EMV (Offline Data Authentication)
SDA · DDA · CDA — authentifier la carte / ses données (pas le porteur).

CVM
Vérification / identification du porteur au POS :
PIN · signature · No CVM. ≠ AuthN carte.

AuthN e-com
3-D Secure / ACS — authentifier le porteur dans le parcours web / in-app.


================================================================================
3. CYCLE EMV
================================================================================
1. Sélection
2. Lecture
3. AuthN carte — SDA / DDA / CDA  ← AuthN carte
4. CVM — vérif. / ID porteur
5. Risque
6. Autorisation (AuthZ)
7. Fin

Ce cycle = carte / POS. Web = autre mécanisme (3DS).


================================================================================
4. CANAUX
================================================================================
1) Carte — SDA/DDA/CDA + CVM
2) Web — AuthN 3DS / ACS
3) Wallet — CDCVM (détail J4)
4) In-app — 3DS / SDK / wallet
